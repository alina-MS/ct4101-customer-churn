# Machine Learning Notebooks

This folder contains the Jupyter notebooks developed for the CT4101 Machine Learning Portfolio Project.

## Milestone 2 — Data Preparation and Baseline

**Notebook:** `customer_churn_milestone2.ipynb`

This notebook contains:

- Loading and exploring the IBM Telco Customer Churn dataset.
- Checking missing values, duplicate records and numerical outliers.
- Preparing the target variable for machine learning.
- Splitting the dataset into training and testing sets.
- Defining preprocessing pipelines for numerical and categorical features.
- Training a majority-class Dummy Classifier as the baseline model.
- Evaluating the baseline using accuracy, precision, recall, F1-score, ROC-AUC and a confusion matrix.

## How to Run

1. Open `customer_churn_milestone2.ipynb` in Google Colab or Jupyter Notebook.
2. Run all cells in order from top to bottom.
3. The notebook downloads the dataset automatically from the IBM GitHub repository.

The notebook requires an internet connection and the Python packages listed in the main repository's `requirements.txt` file.

For the complete project description, dataset information and baseline results, see the main `README.md` in the repository root.
